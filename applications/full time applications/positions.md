## Need Verification

> Applications that hit something an automated worker could not resolve on its own (ambiguous question, unfamiliar flow, broken widget). Add a `# comment` line under an entry to give instructions; a comment containing "skip" moves it to Skipped.

## Skipped

> Positions explicitly deprioritized from Need Verification. Revisit only if time allows.

## Manual Application Required

> Positions where automation was ruled out with strong, reproducible evidence (real image/text CAPTCHA, confirmed anti-bot wall, submit control with zero network effect). Only a human in a real browser can complete these.

## Requires C1 German

> Positions with a hard German C1 requirement tied to a screening question that the candidate's real level does not meet. Never answered dishonestly. Cleared on every triage pass.
